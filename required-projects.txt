# Minimal AOSP project list required to build the logical-partition host tools
# (lpmake / lpdump / lpunpack / lpadd / lpflash) via `mmm`.
#
# One `platform/...` project per line. `repo sync` only checks out the projects
# listed here (plus the build-system bootstrap deps below), so the tree stays
# ~10GB instead of the ~60GB of a full AOSP checkout.
#
# If `mmm` reports a missing module (e.g. "module X not found" or a missing
# include), find the owning project below and append it. Keep this list sorted
# by layer for readability.

platform/build
platform/build/soong
platform/build/blueprint
